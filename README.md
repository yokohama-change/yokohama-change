# YOKOHAMA CHANGE / Japan Change Zero

**0円で「公開情報の変化」を自動収集し、ビジネス価値のある変化だけをスコア化・公開するMVPです。**

## 現在の狙い

単なる「横浜市の新着一覧」ではなく、公開情報から次のようなシグナルを自動抽出します。

- 受注機会（入札・委託・プロポーザル・事業者募集）
- 資金・支援（補助金・助成・融資）
- 開発・不動産（都市計画・市有地・道路・開発許可）
- 制度対応（条例・改正・許認可・届出）
- 営業シグナル（設備投資・創業・出店・採用等）

各変化には、`commercial_score`、`urgency`、`buyer_segments`、`opportunity_type` を自動付与します。

## 自動化済み

1. 横浜市の公式RSS/APIを取得
2. 前回スナップショットとの差分を検出
3. 「新規 / 更新」を判定
4. カテゴリを自動分類
5. 影響度（importance）を0〜100で評価
6. 商用価値（commercial_score）を0〜100で評価
7. 緊急度（urgency）を0〜100で評価
8. 想定利用者（buyer_segments）を自動付与
9. JSON履歴を保存
10. Webダッシュボードへ自動反映
11. 商用候補CSVを自動生成
12. 顧客層別・機会別集計を自動生成
13. GitHub Actionsが3時間ごとに自動実行
14. データが変化した場合だけ自動コミット
15. データ源の一時障害でも既存状態を壊さない
16. Cloudflare Workers用検索APIを同梱

外部AI API、有料DB、有料サーバーは不要です。

## 現在の公式データ源

- 横浜市 市政情報 RSS
- 横浜市 入札・契約 RSS
- 横浜市 中小企業支援 RSS
- 横浜市 事業者向け分野別情報 RSS
- 横浜市オープンデータ CKAN API

`config/sources.json` に追加すれば拡張できます。

## 無料で公開する最短手順

`START_HERE.md` を参照してください。新しいPublic GitHub repositoryを1つ作り、このフォルダの中身をアップロード後、Actionsを1回実行し、Pagesを `/docs` から公開します。

## 自動生成されるデータ

- `docs/data/latest.json` — Web/API用の最新変化データ
- `docs/data/leads.csv` — 商用スコア50以上の候補
- `docs/data/summary.json` — 顧客層別・機会別の集計
- `docs/data/status.json` — 収集元の稼働状況
- `data/history.ndjson` — 内部履歴（最大5000行）
- `data/state.json` — 差分判定用状態

## 重要な耐障害設計

データ源が一時的に落ちた時に空データで状態を上書きすると、復旧時に既存情報が大量に「新規」と誤判定されます。本MVPは、全ソース障害時には状態を保存せず、部分障害時には失敗したソースの既存状態を保持します。

## 法務・ライセンス

`LICENSES_AND_LEGAL.md` を参照してください。

- 横浜市オープンデータ：原則CC BY 4.0。個別条件を確認し、必要なクレジットを表示。
- 横浜市通常Web/RSS：本文を商用データとして転載せず、変化検知・分類・原典リンク中心。
- 横浜市公式サービスと誤認させない。
- 商用・契約・投資等の重要判断は原典確認を促す。
- 個人情報・センシティブ情報のプロファイリングはしない。

## Gビズインフォをまだ入れていない理由

APIトークンの利用申請が必要なため、本人操作なしの0円MVPからは外しています。横浜版で有料価値が確認できてから追加する方針です。

## 収益化判断

最初の2〜4週間、次を自動蓄積します。

- 商用スコア70+の1日平均件数
- 顧客層別（入札・不動産・士業・法人営業）の件数
- 受注機会/資金支援/開発不動産の比率
- 更新から検知までの速さ
- 重複・ノイズ率

この結果で、月額アラート、API、CSV販売のどれを最初に売るか決めます。

## 技術

Python標準ライブラリのみ。APIキーなし。DBなし。GitHub Pagesで静的公開可能。

## API化

`worker/` にCloudflare Workers用のAPIファサードを同梱しています。公開後に `DATA_URL` を `latest.json` へ設定すると、`buyer`、`min_commercial`、`category`、`q` 等で検索できます。
